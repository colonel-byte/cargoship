cargoship_cluster

A Kubernetes cluster cargoship installs, joins and upgrades. One resource holds every host: cargoship takes a cluster-wide lock and starts controllers in a batch of one for quorum, so a resource per node would contend on the lock and lose the ordering batching expresses.

An apply converges the cluster on the configuration. There is no separate install and upgrade: the engine version already on each host is what tells one from the other, and a downgrade is refused rather than attempted.

Example Usage

resource "cargoship_cluster" "prod" {
  name          = "prod-cluster"
  load_balancer = "10.0.0.10"
  package       = "/srv/staging/k3s-v1.33.4.tar.zst"

  profiles = {
    control = {
      node_labels = { "purpose-control" = "true" }
      ports       = [{ port = "6443" }]
      concurrency = "1"
    }
    worker = {
      node_labels = { "purpose-worker" = "true" }
    }
  }

  values = yamlencode({
    addons = {
      disabled = ["traefik"]
    }
  })

  hosts = {
    controller1 = {
      address  = "10.0.0.11"
      role     = "controller"
      key_path = "~/.ssh/id_ed25519"
      profile  = "control"
    }

    worker1 = {
      address  = "10.0.0.21"
      role     = "worker"
      key_path = "~/.ssh/id_ed25519"
      profile  = "worker"
    }
  }
}

Schema

Required

  • load_balancer (String) The address clients use to reach the control plane.
  • name (String) The cluster’s name. It becomes metadata.name and the kubeconfig context, and changing it replaces the cluster.
  • package (String) The distro package to install: a path to a .tar.zst built by cargoship package create, or an OCI reference. A package reference is resolved when the apply runs, so an airgapped management node wants a path.

Optional

  • allow_downgrade (Boolean) Continue when a host already runs an engine newer than the package carries. A downgrade is refused by default, because an engine does not support being moved backwards.
  • allow_unmanaged_nodes (Boolean) Continue when the cluster holds a node no hosts entry accounts for. An apply removes nothing, so by default a node left behind by a deleted entry stops the run.
  • export_kubeconfig (Boolean) Return the cluster’s admin credentials in the kubeconfig attribute. It is off by default and should stay off unless something in the configuration consumes it: the credentials are cluster-admin, and any computed attribute lands in the state file whether or not it is marked sensitive. cargoship install kube-config writes a kubeconfig without putting one in state.
  • hosts (Map of Object) The fleet, keyed by hostname or an identifier of your choosing. The key names the host when hostname is not set, and it is what orders the run: controllers are acted on first, and the controller whose key sorts first becomes the leader.
  • label_nodes (Boolean) Add the node-role.kubernetes.io/<profile> label to each node, from the host’s profile.
  • modify_firewall (Boolean) Rewrite the host firewall (firewalld, ufw or nftables) with the engine’s rules.
  • modify_hosts (Boolean) Rewrite /etc/hosts on every host with the cluster’s own nodes.
  • no_drain_on_destroy (Boolean) Skip draining each node before it is deleted during a destroy. Faster, and it gives workloads no chance to move.
  • profiles (Map of Object) The profiles a host can select, keyed by name. A profile is how a fleet says “every infra node is tainted this way” once rather than per host, and it is also where per-profile concurrency is set.

A host’s own node_labels, node_taints and ports replace its profile’s rather than merging with them; firewall rules are the exception and are unioned. A host that selects a profile this map does not define is a configuration error, since the labels and taints it expected would otherwise silently never exist.

  • retain_on_destroy (Boolean) Leave the cluster running when the resource is destroyed, dropping it from state with a warning instead of resetting it. Destroying resets by default, because that is what destroy means everywhere else.
  • timeout (String) How long the phases wait for a host to reach the state they want, as a Go duration (20m). It bounds the retry loops inside a run, not the run itself.
  • values (String) Overrides for the values the distro package was built with, as a YAML string (e.g. from file("values.yaml") or yamlencode(...)).
  • values_files (List of Object) Paths to YAML values files overriding the values the package ships with. Loaded and merged in order, winning over inline values.
  • worker_concurrency (String) How many workers are installed or upgraded at a time, as a count (5) or a percentage of the batch (25%).

Read-Only

  • distro (String) The engine the package carries, read from the package rather than stated twice. It is what a later refresh and a destroy need.
  • engine_version (String) The engine version the package carries.
  • id (String) The cluster’s name, which is its identity here. There is no import: the hosts entries and their key paths are not recoverable from a running cluster.
  • kubeconfig (String (Sensitive)) The cluster’s admin credentials, populated only when export_kubeconfig is set.
  • nodes (List of Object) What each host reported during the run, in the order the apply acted on them: controllers first.

Nested Attributes

hosts (Map of Object)

The fleet, keyed by hostname or an identifier of your choosing. The key names the host when hostname is not set, and it is what orders the run: controllers are acted on first, and the controller whose key sorts first becomes the leader.

AttributeTypeRequiredDescription
addressStringRequiredThe address or hostname cargoship opens an SSH connection to.
bastionObjectOptionalThe jump host this host is reached through. Cargoship opens its own SSH connections, so a bastion has to be stated here rather than inherited from an SSH client configuration.
environmentMap of ObjectOptionalEnvironment variables cargoship sets on the host, for a proxy or a no-proxy list.
firewall_rulesList of ObjectOptionalFirewall rules for this host. Unlike the fields above, these are unioned with the profile’s rather than replacing them.
hostnameStringOptionalThe name the host is known by before it has been visited.
key_pathStringOptionalPath to the SSH private key on the machine running OpenTofu. There is no attribute for key material, and there will not be: a key in the configuration is a key in the state file.
node_labelsMap of ObjectOptionalKubernetes node labels for this host. They replace the labels of the profile the host selects rather than merging with them.
node_taintsList of ObjectOptionalKubernetes node taints for this host, as key=value:Effect. They replace the profile’s rather than merging with them.
portNumberOptionalThe SSH port. Defaults to 22.
portsList of ObjectOptionalPorts opened on this host, replacing the profile’s.
private_addressStringOptionalOverrides the private address the facts phase would discover.
private_interfaceStringOptionalOverrides the private interface the facts phase would discover, for a node with more than one.
profileStringOptionalThe profile this host selects from the cluster’s profile map, which also becomes its node-role.kubernetes.io/&lt;profile&gt; label when label_nodes is set.
removedBooleanRead-OnlyWhether this host has been removed from the cluster. Computed: it becomes true once a host marked absent has been torn down, and that is what stops the removal from running again.
roleStringRequiredThe host’s role: one of controller, controller+worker, single, worker.
stateStringOptionalThe lifecycle state of this host: present (the default) or absent. Marking a host absent drains it, deletes it from the cluster and uninstalls its engine on the next apply, while every other host keeps running.

The block stays where it is afterwards – removed records that the work is done, so later applies leave the machine alone and never try to reach one that has been decommissioned. Delete the block whenever it suits; nothing depends on it going.

Removal is stated rather than inferred from a deleted block, because deleting the block takes the address and the key path with it: see choice-removed-hosts.
userStringOptionalThe SSH user. Defaults to root.

nodes (List of Object)

What each host reported during the run, in the order the apply acted on them: controllers first.

AttributeTypeRequiredDescription
addressStringRead-OnlyThe address cargoship connected to.
archStringRead-OnlyThe CPU architecture the host reports.
engine_versionStringRead-OnlyThe engine version running on the host, or v0.0.0 for a host with no engine installed. This is the value a plan-time downgrade check compares a package against.
hostnameStringRead-OnlyThe hostname the host reports.
osStringRead-OnlyThe ID from the host’s os-release.
os_versionStringRead-OnlyThe VERSION_ID from the host’s os-release.
private_addressStringRead-OnlyThe private address cargoship discovered, or the one the host block declared.
roleStringRead-OnlyThe role the host block gave it.

profiles (Map of Object)

The profiles a host can select, keyed by name. A profile is how a fleet says “every infra node is tainted this way” once rather than per host, and it is also where per-profile concurrency is set.

A host’s own node_labels, node_taints and ports replace its profile’s rather than merging with them; firewall rules are the exception and are unioned. A host that selects a profile this map does not define is a configuration error, since the labels and taints it expected would otherwise silently never exist.

AttributeTypeRequiredDescription
concurrencyStringOptionalHow many hosts sharing this profile cargoship acts on at once – draining, upgrading, initializing, uninstalling – as a count (1) or a percentage of those hosts (25%). Empty falls back to the phase’s own concurrency.
firewall_rulesList of ObjectOptionalFirewall rules applied to a host selecting this profile. A host’s own rules are unioned with these rather than replacing them.
node_labelsMap of ObjectOptionalKubernetes node labels applied to a host selecting this profile.
node_taintsList of ObjectOptionalKubernetes node taints applied to a host selecting this profile, as key=value:Effect.
portsList of ObjectOptionalPorts opened on a host selecting this profile.
