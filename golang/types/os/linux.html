func (*Alpine) ApplySysctl

func (l *Alpine) ApplySysctl(h configurer.Host, path string) error

ApplySysctl loads the settings in the file at path. Alpine’s sysctl is the busybox applet, which has no --system: it takes one or more files with -p and knows nothing about the /etc/sysctl.d load order the base implementation relies on. Only the file cargoship wrote is applied, so a setting another file overrides keeps whatever value that file gave it until the host next boots and reads them all in order.
